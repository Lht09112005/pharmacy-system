# Frontend

Next.js App Router cho hệ thống quản lý nhà thuốc. Xem hướng dẫn cài/chạy tại [README gốc](../README.md) và [docs/06-development-guide.md](../docs/06-development-guide.md).

Các trang nghiệp vụ hiện chỉ là khung “Đang phát triển”. Health status ở trang tổng quan gọi API thật qua `NEXT_PUBLIC_API_BASE_URL`.
