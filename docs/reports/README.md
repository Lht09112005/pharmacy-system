# Báo cáo môn học

Thư mục để nhóm đưa file Word báo cáo và bản xuất PDF khi cần. Gói này tập trung tài liệu Markdown cho khởi tạo dự án, không kèm bản Word cũ để tránh dùng nội dung đã lỗi thời làm đặc tả code.

Sau thay đổi đã được chốt, cập nhật cả tài liệu Markdown, sơ đồ và báo cáo. Chương IV–VI chỉ ghi kết quả triển khai/kiểm thử đã thực hiện.
