# Mã nguồn sơ đồ

- [ERD](erd.mmd): quan hệ chính của 17 bảng.

Mở bằng công cụ hỗ trợ Mermaid để xem hoặc xuất ảnh. Đây là nguồn sơ đồ, không phải ảnh đã render. Các điểm chi tiết, trạng thái lỗi và giao dịch đồng thời xem tài liệu 02–04.
